# Contributing

Thanks for your interest in Mailrust.

## Pull requests

Mailrust does not take pull requests yet. It is a one-person project, and I cannot review outside code right now. Pull requests will be closed without review.

This may change later. This file will say so when it does.

## Bug reports and ideas

These are welcome. Open an issue with the bug or feature form.

## Security problems

Do not open a public issue. See [SECURITY.md](SECURITY.md).

## Running it yourself

You are free to fork Mailrust under the terms of the [AGPL-3.0 license](LICENSE). The README has the quick start and the development commands.
