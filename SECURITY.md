# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a problem

Please do not open a public issue for a security problem.

Report it in private with the **Report a vulnerability** button on the [Security tab](https://github.com/irfanfaraaz/mailrust/security/advisories/new). Include:

- what the problem is and what an attacker could do with it,
- the steps to reproduce it,
- the Mailrust version or commit.

You will get an answer within 7 days. When a fix is out, you will be credited in the release notes, unless you ask not to be.
